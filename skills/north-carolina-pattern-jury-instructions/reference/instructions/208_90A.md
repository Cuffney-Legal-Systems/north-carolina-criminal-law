1. Where the charge involves use of a firearm under the statute, use N.C.P.I.-Crim.

208.90.

2. For purposes  of  this  statute,  property  is  described  as  any  building,  structure,
vehicle,  aircraft,  watercraft,  or  other  conveyance,  device,  equipment,  erection  or
enclosure.

3. N.C. Gen. Stat.   14-34.1 forbids attempting to discharge a barreled weapon into

occupied property as well as the actual discharge.

If only an "attempt" is charged and the judge believes that it is a type covered by
the  statute,  the  instruction  may  be  modified  accordingly.    If  an  instruction  explaining
"attempt" is required, see N.C.P.I.-Crim. 201.10.

4.  The  parenthetical  phrase  should  be  used  only  where  there  is  evidence  of

justification or excuse, such as self-defense.
