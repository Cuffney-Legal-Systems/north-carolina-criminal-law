220.97 [POSSESSION] [TRANSFER] [USE] OF AUTOMATED SALES
SUPPRESSION DEVICE. FELONY.

The defendant has been charged with [possession] [transfer] [use]

of an automated sales suppression device.

For you to find the defendant guilty of this offense, the State must

prove two things beyond a reasonable doubt.

First, that the defendant [sold] [purchased] [installed] [transferred]

[possessed] [used] [accessed] an automated sales [suppression  device]

[zapper]1 [phantom-ware].2

And Second, that the defendant did so knowingly.

If you find from the evidence beyond a reasonable doubt that on or

about  the  alleged  date  the  defendant  knowingly  [sold]  [purchased]

[installed]  [transferred]  [possessed]  [used]  [accessed]  any  automated

sales  [suppression  device]  [zapper]  [phantom-ware],3  it  would  be  your

duty  to  return  a  verdict  of  guilty.4  If  you  do  not  so  find  or  have  a

reasonable  doubt  as  to  one  or  more  of  these  things,  then  it  would  be

your duty to return a verdict of not guilty.

1 For purposes of this section, an automated sales suppression device or zapper is a
software program that falsifies the electronic records of electronic cash registers and other
point of sale systems, including transaction data and transaction reports. The term includes
the software program, any device that carries the software program, or an Internet link to
the software program. For a definition of an electronic cash register see N.C. Gen. Stat.
14-118.7(2). For a definition of transaction data see N.C. Gen. Stat.   14-118.7(4). For a
definition of transaction report see N.C. Gen. Stat.   14-118.7(5).

2  For  purposes  of  this  section,  phantom-ware  is  a  hidden  programming  option
embedded  in  the  operating  system  of  an  electronic  cash  register  or  hardwired  into  the
electronic  cash  register  that  can  be  used  to  create  a  second  set  of  records  or  may
eliminate or manipulate transaction records, which may or may not be preserved in digital
formats, to represent the true or manipulated record of transactions in the electronic cash
