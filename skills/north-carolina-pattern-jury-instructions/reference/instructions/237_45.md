237.45 PROVIDING FALSE INFORMATION IN ORDER TO OBTAIN A LICENSE
TO OPERATE  A BEACH BINGO GAME. MISDEMEANOR.

The defendant has been charged with providing false information in

order to obtain a license to operate a beach bingo game.

For you to find the defendant guilty of this offense, the State must

prove three things beyond a reasonable doubt:

First, that on or about the alleged  date,  the  defendant  submitted

an application as prescribed by the State Bureau of Investigation in order

to operate a beach bingo game1 within the State of North Carolina.

Second,  that  the  defendant  provided  false  information2  on  [his]

[her] application submitted to the State Bureau of Investigation3 in order

to obtain a license to operate a beach bingo game by (describe the false

information on the application).

And Third, that the defendant did so knowingly.

If you find from the evidence beyond a reasonable doubt that on or

about  the  alleged  date,

the  defendant  knowingly  submitted  an

application as prescribed by the State Bureau of Investigation in order to

operate a beach bingo game within the State of North Carolina, and that

the  defendant  provided  false  information  on  [his]  [her]  application

submitted  to  the  State  Bureau  of  Investigation  by  (describe  the  false

information on  the  application), then it  would  be  your  duty  to  return  a

verdict of guilty.  If you do not so find or have a reasonable doubt as to

one or more of these things, it would be your duty to return a verdict of

not guilty.
