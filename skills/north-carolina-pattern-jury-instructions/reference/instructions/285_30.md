285.30 [DESTRUCTION OF] [FAILURE TO DELIVER] ABSENTEE BALLOT.
FELONY.

The defendant has been charged with the [destruction of] [failure

to deliver] an absentee ballot.

For you to find the defendant guilty of this offense, the State must

prove two things beyond a reasonable doubt.

First,

that

the  defendant

intentionally  [[failed

to  deliver]

[destroyed]]  [[a  completed  written  request  for  an]  [a  completed

application for an] [a voted]] absentee ballot.

And Second, that the defendant did so with the intent to obstruct a

vote by a registered voter.

If you find from the evidence beyond a reasonable doubt that on or

about  the  alleged  date,  the  defendant  intentionally  [[failed  to  deliver]

[destroyed]]  [[a  completed  written  request  for  an]  [a  completed

application for an] [a voted]] absentee ballot with the intent to obstruct

a vote by a registered voter, it would be your duty to return a verdict of

guilty. If you do not so find or if you have reasonable doubt as to one or

both of these things, then you would return a verdict of not guilty.
