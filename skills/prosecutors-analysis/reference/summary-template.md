# Prosecutorial Summary — Report Template

**Target length scales with the case: ≈ 900 words of core + ≈ 250 per charge.**
Two charges ≈ 1,400 words (2–3 pages); four ≈ 1,900; six ≈ 2,400. This is a
target, not a ceiling. A draft that runs over is usually padded — but a draft
that hits the number by dropping facts has failed the prosecutor relying on it.
Cut explanation. Never cut a fact, a weakness, a defense, a discrepancy, or a
fact gap. If the case needs the room, take it and say so in one line.

**Audience: a career prosecutor.** They know the law. Do not explain what an
element means, why intent matters, what "constructive possession" is, or why
probable cause is the standard. State the element, state the proof, state the
verdict. Legal exposition is the single largest source of bloat.

**Say each fact once — and the Summary is where facts live.** The division of
labor is: **Section 1 carries the narrative record; Sections 2–6 carry the
verdicts, problems, and recommendations.** A fact belongs in the chronology.
Later sections point back in a short phrase ("the clothing mismatch," "Doe 1's
show-up ID," "the March 20 CODIS hit") and add only what is *new* — the element
it proves, the weakness it creates, the defense it raises. Re-narrating the
incident under Weaknesses, and again under Identification, is what turns three
pages into fifteen.

The Summary is the factual record; it is not a place to pre-argue the elements.
No verdicts, no "this supports," no "the State will need."

---

## Document header

```
PROSECUTORIAL SUMMARY — DRAFT FOR PROSECUTOR REVIEW
Case: [case / agency report number]     Prepared: [date]
Defendant(s): [names, or John/Jane Doe 1 for redacted reports]
Charges: [statute cites + offense names, exactly as charged]
Source: [documents reviewed]
AI-assisted screening draft — not a charging decision.
```

Immediately under the header, when one exists, a single flag line for the issue
that most threatens the case:

```
> **⚠ CASE-CRITICAL — [six-word issue]:** [one sentence]. *See [section].*
```

At most **two** such flags in a report. They lose all force if used routinely.

## 1. SUMMARY

**A factual chronology of the report — roughly 450–650 words, in two parts.**
This is the section a prosecutor reads to understand *what happened*, and it is
the only section that carries the narrative record. It should be detailed enough
that someone who has never opened the report can run the file from it. It is the
one section where completeness beats compression.

Facts only. No element analysis, no argument, no verdicts — those are Sections
2–6.

### 1A. The incident

**Narrative prose, ~200–300 words**, following the report's own sequence: how it
started, who was present and where, what each person did and said, the weapon
and how it was used, injuries, property taken or damaged, how it ended, and the
immediate police response. Set the scene — time of day, lighting, location type,
who was with whom — because those facts decide identification and defenses
later.

### 1B. Investigative chronology

**Dated entries, one per meaningful investigative step**, from the first
response through the most recent supplement. Each entry: **bolded date**, what
was done, and what it produced — including the steps that produced nothing.

```
- **12/23/2017, 2304** — Call received as armed robbery from person; Ofc. [X]
  responded. K9 track requested and cancelled — *"the time lapse (30 mins) and
  the amount of foot traffic."*
- **12/24/2017** — CSS processed the truck; collected photographs, a latent
  print, and suspected blood from the exterior driver door frame.
- **02/23/2018** — Lab: male DNA profile obtained, entered in CODIS. **No match.**
```

Include the negative and dead-end steps — a cancelled K9 track, an unreturned
call, a lab request with no result reported, a witness never re-contacted. What
the investigation *did not* do is case information, and it is invisible unless
the chronology shows it.

Where the report gives a date but no outcome (a lab request with no report, a
follow-up assigned but never closed), say so in the entry. Those become fact
gaps in Sections 3 and 6 — but they are recorded here first.

### Rules for both parts

- **Every entry traces to a narrative.** Attribute by source (`Narr. #3`,
  `Det. supplement 05/07/2018`) so the prosecutor can find it in the file.
- **Quote rather than paraphrase** where the report's own words carry the fact.
- **Bold** the facts the case actually turns on, and the dates in 1B.
- Where narratives conflict, give both in one clause — *"a **white** Nissan
  (Ofc. Reyes) or **grey/silver** (victim)"* — and carry the conflict to
  Weaknesses. Never silently pick a version.
- **No inferred facts.** If the report does not say the vehicle was occupied,
  the chronology does not say it either.

## 2. CHARGE ANALYSIS

Elements and analysis are **merged**. Listing elements and then re-narrating
the same facts underneath them is the primary cause of overlong drafts.

One block per charge. Format:

```
### Charge 1 — [Offense], G.S. 14-__ (Class __)
*Elements per N.C.P.I.—Crim. ___.__ (rev. 20__).*

| # | Element (pattern language) | Status | Proof in the record |
|---|---|---|---|
| 1 | [verbatim or tightly condensed pattern text] | **SUPPORTED** | "[direct quote]" — [source] |
| 2 | ... | **CONTESTED** | "[direct quote]" — [source] |
| 3 | ... | **GAP** | No fact in the report as to [x]. |
```

Rules for the table:

- **Element column** uses the pattern instruction's own words. Condensing is
  permitted (drop bracketed alternatives that don't apply); paraphrasing is
  not. This was evaluators' #1 criticism of the baseline outputs.
- **Status** is one of **SUPPORTED** / **CONTESTED** / **NOT SUPPORTED** /
  **GAP** — bolded, all caps, nothing else in the cell.
- **Proof column** carries a **direct quote from the report** wherever one
  exists, with its source (narrating officer, witness, page or supplement).
  Keep quotes under about 25 words. A quote in the table replaces a paragraph
  of narration — this is where the page count is won.

Below the table, add prose **only** for elements marked CONTESTED, NOT
SUPPORTED, or GAP — one to three sentences each, in this shape: *what is
missing → what would fix it.* Elements marked SUPPORTED get no prose at all;
the table already said everything.

Cap each charge block at roughly **150 words of prose** beyond the table.

**Multiple defendants on the same offense: do not repeat the element table.**
Build it once for the defendant whose conduct is most fully documented, then
give each additional defendant a short block covering *only* what actually
differs — normally identity and acting in concert (*N.C.P.I.—Crim. 202.10*) —
in a two- or three-row table of its own. One line states that the remaining
elements are proved by the same conduct. Re-running seven elements per
defendant doubles the page count and adds nothing.

Never present a separate offense (assault on a female, assault on a government
officer) as an "aggravating factor" of a base assault — in North Carolina
these are distinct crimes and get their own block.

Where a defense instruction is in play, its requirements go in the **Defenses**
section, not here.

## 3. WEAKNESSES

**Bullets, ≤ 6, one to two lines each.** The section prosecutors weight most
heavily, and the one that stays sharp only if it lists real problems rather
than reciting categories.

Each bullet: **bolded label** — the problem, with a quote where the report
supplies one. Example:

> - **Weapon never recovered.** The pistol described by both witnesses was not
>   located in the vehicle or on the defendant's person.
> - **Clothing mismatch.** Doe 1 described *"an orange sweater"*; the defendant
>   was booked in a red hoodie.

Sweep for, but list only what you actually find: evidence not recovered
(weapon, property, casings); missing or unhelpful surveillance/BWC/forensics;
eyewitness limits (lighting, distance, duration, "did not get a good look");
description-vs-appearance discrepancies; internal contradictions in the report;
chain-of-custody, translation, or response-delay problems; credibility exposure
on cross; and the charge-specific proof problems from `issue-checklists.md`.

If a sweep category came up empty, say nothing about it. Close the section
instead with one line naming what was checked and found clean. Never omit the
section, and never write "none noted" without that line.

## 4. DEFENSES

**≤ 120 words.** Every defense the facts could plausibly raise, whether or not
anyone used its name — self-defense, defense of others, accident, alibi,
consent, lack of intent. A claim appearing anywhere in the report (*"she said
it was an accident"*) **must** be analyzed against its pattern instruction,
with the facts on both sides, in two or three sentences:

> **Self-defense** (*N.C.P.I.—Crim. 308.45*). Supported by the defendant being
> found *"on the ground underneath"* the victim. Rebutted by the BWC showing
> the victim walking away when the shot was fired.

Physical positioning and "it just went off" statements trigger this section
even when no one says "self-defense." Accident and self-defense are separate —
address each. If nothing is supported, say so in one sentence and name what you
looked for.

## 5. IDENTIFICATION

**≤ 120 words.** How the defendant was tied to the offense — eyewitness ID
(show-up / photo lineup / spontaneous), forensics (say *where* the sample came
from), surveillance, admission, vehicle association, prior officer familiarity.

Then the reliability problems only: description mismatches, **show-up
suggestibility** (name it whenever a show-up was used), **any failed or
non-identification** (report it even when other ID evidence is overwhelming),
and viewing conditions. Do not re-narrate the identification facts already in
the Summary.

## 6. BOTTOM LINE

**One line per charge**, in a table — the prosecutor's first read and often
their only read:

| Charge | Probable cause | Recommendation |
|---|---|---|
| Robbery w/ dangerous weapon, G.S. 14-87 | **No — weapon element fails** | *Proceed on common law robbery* |
| Conspiracy, G.S. 14-2.4 | **Yes** | *Proceed as charged* |

Then at most **three sentences** total: the single thing that most needs
resolving before charging, and any well-supported offense noticed outside the
charges requested.

Recommendation language is sufficiency-only — *proceed as charged*, *proceed on
the lesser included*, *obtain [specific evidence] first*, *decline*. Never "the
State will convict" or "this charge will fail at trial."

Close with:

```
Verification pass completed: facts traced to source, discrepancy sweep run,
element language checked against N.C.P.I.—Crim. [numbers].

AI-assisted screening draft. Not a probable-cause determination. Under N.C.
RPC 3.8 and ABA Standard 3-4.3 the charging decision rests with the
prosecutor after independent review of the source materials.
```

## Length budget at a glance

Section budgets are *guides for the typical case*. Where a section has more real
content — a fifth genuine weakness, a second defense actually raised, a third
identification problem — carry it and let the section run over. Where it has
less, come in under. The number to protect is the completeness of the record,
not the row in this table.

| Section | Guide | Scales with charges? |
|---|---|---|
| Header + flag | 6 lines | no |
| 1. Summary | ~450–650 words (1A narrative + 1B dated chronology) | with report length, not charge count |
| 2. Charge analysis | table + ~150 words prose **per charge** | **yes** |
| 3. Weaknesses | ~6 bullets | slightly |
| 4. Defenses | ~120 words | no |
| 5. Identification | ~120 words | no |
| 6. Bottom line | table + ~3 sentences | one row per charge |

Total ≈ **1,200 core + 250 per charge**. The Summary is the largest fixed cost
and the one worth paying: it grows with how much investigation the report
documents, not with how many charges were signed out. Element tables and
verbatim quotes are what keep the rest of the budget achievable — count prose
against it, not them.

## Formatting conventions

These are written as markdown because markdown is the working draft. **The
delivered file is a `.docx`** — see Step 7 of `SKILL.md` for how each convention
below must be rendered in Word. Every one of them has to survive the conversion;
element tables in particular must become real Word tables, never lists.


- **Bold** — status verdicts, bullet labels, and the two or three facts the
  case turns on. Nothing else, or the emphasis stops working.
- *Italic* — instruction and statute cites, recommendations, and quoted report
  language run inline.
- `>` blockquote — the case-critical flag line, and any quote long enough to
  stand on its own.
- Tables — elements and the bottom line. Never a wall of prose where a table
  fits.
- Quotes — verbatim, under ~25 words, always attributed to a narrative,
  witness, or supplement. Ellipses for trims; never alter wording to smooth it.
