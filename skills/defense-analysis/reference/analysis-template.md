# Defense Case Analysis — Report Template

**Target length: ≈ 1,400 words of core + ≈ 250 per charge — with Section 3
exempt.** Two charges ≈ 1,900 words of core plus however long the weaknesses
run; four ≈ 2,400 plus the same. Sections 1, 2, 4, 5, 6 and 7 are budgeted.
**Section 3 is not.** It runs as long as the record supports and stops when the
record does.

**Audience: a trial lawyer who tries these cases.** They know the law. Do not
explain what an element means, what constructive possession is, or what *Miranda*
requires. Name the problem, quote the proof, name the use. Legal exposition is
the single largest source of bloat.

**Every assertion is attributed.** This is the rule that distinguishes a defense
memo from a police report with different formatting. *"Doe 1 told Ofc. Reyes the
lot was dark"* — never *"the lot was dark."* An unattributed allegation is a fact
counsel may stop testing.

**Say each fact once — and the Summary is where facts live.** Section 1 carries
the narrative record; Sections 2–7 carry attacks, defenses, and tasks. Later
sections point back in a short phrase ("the clothing mismatch," "the 06/04
array," "the uncanvassed block") and add only what is *new* — the element it
undercuts, the motion it feeds, the cross it sets up.

The Summary is the factual record; it is not a place to pre-argue. No verdicts,
no "this fails," no "the State cannot prove."

---

## Document header

```
DEFENSE CASE ANALYSIS — ATTORNEY WORK PRODUCT — PRIVILEGED
Client: [name or Doe designation]     Prepared: [date]
Case: [case / agency report number]   Charges (client): [statute cites + offense names as charged]
Codefendants: [names/designations, or "none identified"]
Source: [documents reviewed]
AI-assisted work-product draft for defense counsel. Not a filing. Not advice to the client.
```

Immediately under the header, when one exists, a single flag line for the **best
issue in the case** — the one thing counsel should act on first:

```
> **★ BEST ISSUE — [six-word issue]:** [one sentence]. *See [section].*
```

At most **two** such flags. They lose all force if used routinely. Where a
conflict or *Bruton* problem exists, that is always one of them.

## 1. SUMMARY

**A factual chronology of the State's materials — roughly 500–700 words, in two
parts.** This is the section counsel reads to understand *what the State says
happened*, and it is the only section that carries the narrative record. It
should be detailed enough that someone who has never opened the file can run the
case from it.

Facts only, all attributed. No element analysis, no argument, no verdicts.

### 1A. The State's account of the incident

**Narrative prose, ~250–350 words**, following the report's own sequence: how it
started, who was present and where, what each person did and said, the weapon and
how it was used, injuries, property taken or damaged, how it ended, and the
immediate police response. Set the scene — time of day, lighting, location type,
who was with whom — because those facts decide identification and defenses later.

Two defense-specific rules on top of the shared ones:

- **Attribute every assertion** to its source, in the sentence: *"Doe 1 told Ofc.
  Reyes…," "Per Narr. #3…," "Ofc. Reyes wrote that…."* Where the report states
  something with no attributed source at all, say so — an unsourced assertion in
  a narrative is itself a cross-examination point.
- **Mark the conclusions.** Where the report asserts a legal or medical
  conclusion (*"serious injury," "confessed," "a dangerous weapon," "resisted"*),
  render it as the report's characterization and note what fact, if any, is
  offered for it.

### 1B. Investigative chronology

**Dated entries, one per meaningful investigative step**, from the first response
through the most recent supplement. Each entry: **bolded date**, what was done,
and what it produced — **including every step that produced nothing.**

```
- **12/23/2017, 2304** — Call received as armed robbery from person; Ofc. [X]
  responded. K9 track requested and **cancelled** — *"the time lapse (30 mins)
  and the amount of foot traffic."*
- **12/24/2017** — CSS processed the truck; collected photographs, a latent
  print, and suspected blood from the **exterior** driver door frame.
- **02/23/2018** — Lab: male DNA profile obtained, entered in CODIS. **No match.**
- **05/07/2018** — Supplement assigns follow-up canvass. **No canvass report
  appears in the production.**
```

On the defense side the negative entries are the point, not a courtesy. A
cancelled K9 track, an uncanvassed block, an unreturned call, a lab request with
no result, a follow-up assigned but never closed, a witness never re-contacted —
each is a reasonable-doubt argument and each is invisible unless it is here.

**Also record what was referenced but not produced.** A supplement, BWC
recording, 911 call, photo array, or lab report the narrative mentions that is
not in the materials provided gets its own entry marked **NOT IN PRODUCTION**.
Those become Section 7 discovery demands.

### Rules for both parts

- **Every entry traces to a narrative.** Attribute by source (`Narr. #3`, `Det.
  supplement 05/07/2018`) so counsel can find it in the file.
- **Quote rather than paraphrase** where the report's own words carry the fact.
- **Bold** the facts the case actually turns on, and the dates in 1B.
- Where narratives conflict, give both in one clause — *"a **white** Nissan (Ofc.
  Reyes) or **grey/silver** (Doe 1)"* — and carry the conflict to Section 3.
  Never silently pick a version.
- **No inferred facts, in either direction.** If the report does not say the
  vehicle was occupied, the chronology does not say it either — and it does not
  say it was empty.

## 2. CHARGE ANALYSIS

One block per charge **against the client**. Elements and analysis are merged.

```
### Charge 1 — [Offense], G.S. 14-__ (Class __)
*Elements per N.C.P.I.—Crim. ___.__ (rev. 20__). Lesser included: [offense], N.C.P.I. ___.__*

| # | Element (pattern language) | State's proof in the record | Strength | Defense attack |
|---|---|---|---|---|
| 1 | [verbatim or tightly condensed pattern text] | "[direct quote]" — [source] | **STRONG** | — |
| 2 | ... | "[direct quote]" — [source] | **CONTESTED** | Single witness; night lighting; see §5 |
| 3 | ... | Nothing in the record as to [x]. | **NO PROOF** | Motion to dismiss at close of State's evidence |
```

Rules for the table:

- **Element column** uses the pattern instruction's own words. Condensing is
  permitted (drop bracketed alternatives that don't apply); paraphrasing is not.
  A paraphrased element is a missed defense — the motion to dismiss is measured
  against the pattern language, not against a summary of it.
- **State's proof column** carries a **direct quote from the report** wherever one
  exists, with its source. Keep quotes under about 25 words. Where there is no
  proof, say so in a short declarative — *"Nothing in the record attributes the
  firearm to the client."*
- **Strength** is exactly one of **STRONG** / **CONTESTED** / **WEAK** /
  **NO PROOF** — bolded, all caps, nothing else in the cell:

  | Verdict | Meaning |
  |---|---|
  | **STRONG** | Direct, attributed evidence a jury would readily accept. Don't spend trial capital here. |
  | **CONTESTED** | Evidence exists but rests on a witness, an inference, or a disputed fact. Where cross works. |
  | **WEAK** | Thin, purely circumstantial, or internally contradicted. A live sufficiency argument. |
  | **NO PROOF** | Nothing in the record establishes it. Motion to dismiss at the close of the State's evidence. |

- **Defense attack** is one clause, concrete: the cross point, the missing fact,
  the suppression theory, the competing inference, the instruction to request. An
  element with no attack gets *"—"*. Do not manufacture one.

Below the table, prose **only** for elements rated WEAK or NO PROOF — one to
three sentences each, in this shape: *what the State lacks → why this record
cannot supply it → what motion or argument it feeds.* STRONG and CONTESTED
elements get no prose; the table already said it.

Cap each charge block at roughly **150 words of prose** beyond the table.

**Be honest about STRONG.** The value of the WEAK verdicts comes entirely from
the credibility of the STRONG ones. A memo that rates every element vulnerable
tells counsel nothing.

**Acting in concert / accessory theories get their own short block.** Where the
client's exposure runs through *N.C.P.I.—Crim. 202.10* (acting in concert), a
conspiracy instruction, or an aiding-and-abetting theory rather than through the
client's own conduct, build a two- or three-row table for that theory — presence,
common purpose, acts in furtherance — and analyze it separately. Mere presence is
usually the attack. Do not bury this inside the substantive element table; it is
frequently the whole case.

**Lesser included offenses.** Name them under each charge with their instruction
numbers, and say in one line whether the record supports the lesser where it does
not support the greater. This is the fallback verdict counsel may want charged
and the shape of any negotiation.

## 3. WEAKNESSES IN THE STATE'S CASE

**The section this document exists for. No length cap, no bullet cap.** Organize
under labeled sub-headings; use only the sub-headings that have hits. Within
each, bullets of one to three lines.

Every bullet has the same four parts: **bolded label** — the problem in the
report's own words — the source — **the use**. The use is what makes this work
product rather than commentary. Example:

> **Witness credibility and reliability**
>
> - **Complainant's two accounts conflict.** Doe 1 told Ofc. Reyes the gunman
>   *"came from the sidewalk behind me"*; in the 06/03 interview she said he
>   *"was already standing by the car."* (Narr. #1 vs. Det. supplement 06/03.)
>   **Use:** cross on the change; request *N.C.P.I.—Crim. 105.20* (impeachment by
>   prior statement).
>
> **Investigative gaps and police work**
>
> - **Block never canvassed.** The 06/04 supplement records that the 400-block
>   businesses *"were not canvassed"* for surveillance; no canvass appears in the
>   production and retention windows have likely run. **Use:** closing argument on
>   the adequacy of the investigation; preservation letter now in case footage
>   survives.

Sub-headings to sweep, in this order — include only those with hits:

1. **Witness credibility and reliability** — prior inconsistent statements,
   interest and bias (charged codefendant, cooperating witness, pending
   charges, relationship to the complainant), intoxication, opportunity to
   observe, memory gaps, recorded vs. summarized statements, statements taken
   only as an officer's paraphrase, delay in reporting, motive to fabricate.
   Name the corresponding instruction where one exists (*104.20* interested
   witness, *104.25* accomplice testimony, *104.30* informer, *105.20/105.21*
   impeachment).
2. **Investigative gaps and police work** — steps not taken, leads not followed,
   scenes not canvassed, evidence not collected or not tested, witnesses not
   re-contacted, BWC not activated or not pulled, notes destroyed or not
   preserved, reports written days later, conclusory narrative language, a single
   officer's account with no corroboration, chain-of-custody gaps, translation
   handled by a bystander or an officer without certification.
3. **Physical and forensic evidence** — what was never recovered (weapon,
   property, casings, clothing); what was recovered but never tested; **where** a
   sample came from and what that does and does not prove (DNA on the outside of
   a vehicle proves presence near it, not inside it); mixture and touch-DNA
   limits; latent print quality; surveillance that does not show the contested
   fact; lab reports absent from the production; whether an expert is needed.
4. **Identification** — cross-reference only. Detail lives in Section 5.
5. **Internal contradictions in the report** — descriptions of people, vehicles,
   and property that differ across narratives; timeline impossibilities; a
   property log that does not match the narrative (*"handgun"* in the narrative,
   *"airsoft pistol"* on the log); counts that do not match the charging
   language. List every one, including the small ones. Small contradictions are
   how a witness loses a jury.
6. **Constitutional and suppression exposure** — the basis for the stop, the
   frisk, the search, the entry; consent and who gave it; warrant, application,
   and return; *Miranda* and whether custody and interrogation are documented;
   whether the interrogation was electronically recorded (G.S. 15A-211 —
   *verify*); show-up and lineup procedure against the Eyewitness Identification
   Reform Act (G.S. 15A-284.52 — *verify*); *Bruton* problems from a
   codefendant's statement; *Brady* / *Giglio* material not produced. Each hit
   names the motion and the ground; the supporting authority is flagged
   *(verify)* and confirmed by counsel before filing.
7. **Charging and procedural defects** — variance between the charging language
   and the facts; a fatally defective warrant or indictment; wrong offense date;
   jurisdiction and venue; statute of limitations on misdemeanors; joinder that
   should be severed; two counts arising from a single act (merger /
   double-jeopardy question); speedy-trial posture.
8. **Charge-specific proof problems** — the hits from
   `weakness-checklists.md` for the offenses actually charged.

Close the section with one line naming what was swept and came up clean. Never
omit the section, and never write "none noted" without that line.

## 4. DEFENSES

**≤ 250 words.** Every defense the record could plausibly raise, whether or not
anyone used its name. Work from `defenses-catalog.md`; load and cite the pattern
instruction for each one analyzed.

For each: **what supports it** (with the quote), **what rebuts it**, **who
carries the burden** — taken from the loaded instruction's own mandate paragraph,
never from memory — and **what would develop it**.

> **Self-defense** (*N.C.P.I.—Crim. 308.45 (rev. 2023)*). Supported by the client
> being found *"on the ground underneath"* the complainant (Narr. #2). Rebutted
> by the BWC showing the complainant walking away when the shot was fired.
> Burden: per the instruction, the State must prove beyond a reasonable doubt
> that the client did not act in self-defense once the issue is raised — confirm
> against the loaded text. **Develop:** full BWC from both responding units;
> medical records documenting the client's injuries.

Separate **affirmative defenses** (self-defense, accident, duress, necessity,
entrapment, alibi, insanity, automatism) from **failures of the State's proof**
(mere presence, misidentification, lack of intent, no possession, claim of
right). Both are legitimate; they are not the same thing and the burdens differ.

Physical positioning, "it just went off" statements, intoxication, and any
mention of a third party's threats trigger this section even when no one uses the
defense's name. Accident and self-defense are separate — address each. If nothing
is supported by the record, say so in one sentence and name what you looked for.
Do not invent a defense the record does not reach.

## 5. IDENTIFICATION

**≤ 200 words.** How the State ties **the client** to the offense — eyewitness ID
(show-up / photo lineup / spontaneous), forensics (say *where* the sample came
from), surveillance, admission, vehicle association, prior officer familiarity.

Then the attack, which is most of the section: description mismatches against the
client's documented appearance at arrest; **show-up suggestibility** (name it
whenever a show-up was used); **every failed or non-identification**, including
by other witnesses; viewing conditions (lighting, distance, duration, elapsed
time, *"did not get a good look"*); whether the array complied with the
Eyewitness Identification Reform Act (G.S. 15A-284.52 — *verify*) and whether an
independent administrator was used; cross-racial identification; whether an
eyewitness-identification expert is warranted. Name *N.C.P.I.—Crim. 104.90* and,
where a photo array was used, *104.98* as instructions to request.

Do not re-narrate the identification facts already in Section 1.

## 6. BOTTOM LINE

**One line per charge**, in a table — counsel's first read and often their only
read:

| Charge | State's proof | Defense posture |
|---|---|---|
| Robbery w/ dangerous weapon, G.S. 14-87 | **Weapon element: NO PROOF** | *Move to dismiss the 14-87; exposure is common law robbery* |
| Conspiracy, G.S. 14-2.4 | **Strong — "run that" statement** | *Not a trial issue; negotiate* |

Then at most **four sentences** total, covering:

- The **single best issue** and what to do with it first.
- The **realistic exposure** if every weak charge falls — stated as which offense
  the record supports, never as a sentence prediction.
- What most needs resolving before counsel can assess the case.

Posture language is leverage-and-sufficiency only — *move to dismiss*, *move to
suppress*, *try the identification*, *seek the lesser-included instruction*,
*negotiate*, *investigate before assessing*. **Never** "the client will be
acquitted," "the charge will be dismissed," or "the motion will be granted."

## 7. ACTION ITEMS

**A working list, grouped by urgency.** Short imperative lines; each names who or
what it goes to. This section is why the analysis is useful the week counsel
reads it.

```
### Immediate (this week)
1. Preservation letter to [business] for 12/23 exterior camera footage — retention likely 30 days.
2. Client interview: the client's account of the stop, the search, and any statement to Ofc. [X].

### Discovery to demand (G.S. 15A-903 — verify)
3. Full BWC from all responding units, not the clips referenced in Narr. #1.
4. The 06/04 photo array, the admin's instructions, and the filler photos.
5. Lab report referenced in the 02/23 supplement — not in the production.
6. Any Giglio material on Ofc. [X].

### Motions to consider (deadlines per G.S. 15A-952 — verify)
7. Motion to suppress the show-up identification — suggestive procedure.
8. Motion to sever — codefendant's statement implicates the client (Bruton).

### Investigation
9. Locate and interview the bystander who called the second 911.
10. Retain an eyewitness-identification expert if the ID is tried.
```

Keep it to what the record actually supports. Ten real items beat thirty
generic ones.

Close with:

```
Verification pass completed: assertions traced and attributed to source,
client-scoping checked, discrepancy sweep run, element language checked against
N.C.P.I.—Crim. [numbers].

ATTORNEY WORK PRODUCT — PRIVILEGED. AI-assisted draft prepared for defense
counsel's review. Not a filing, not advice to the client, and not a prediction
of outcome. Authority outside the local G.S. Chapter 14 and N.C.P.I. libraries
is flagged (verify) and must be confirmed before use.
```

## Length budget at a glance

Section budgets are *guides for the typical case*. Where a section has more real
content, carry it and let the section run over. The number to protect is the
completeness of the issue inventory, not the row in this table.

| Section | Guide | Scales with charges? |
|---|---|---|
| Header + flag | 7 lines | no |
| 1. Summary | ~500–700 words (1A narrative + 1B dated chronology) | with report length, not charge count |
| 2. Charge analysis | table + ~150 words prose **per charge** | **yes** |
| 3. Weaknesses | **no cap** — as long as the record supports | yes, substantially |
| 4. Defenses | ~250 words | slightly |
| 5. Identification | ~200 words | no |
| 6. Bottom line | table + ~4 sentences | one row per charge |
| 7. Action items | ~10 lines | slightly |

Core ≈ **1,400 + 250 per charge**, plus Section 3 at whatever length the record
justifies. Element tables and verbatim quotes are what keep the rest achievable —
count prose against the budget, not them.

## Formatting conventions

These are written as markdown because markdown is the working draft. **The
delivered file is a `.docx`** — see Step 9 of `SKILL.md`. Every convention has to
survive the conversion; element tables in particular must become real Word
tables, never lists.

- **Bold** — strength verdicts, bullet labels, **Use:** lead-ins, and the two or
  three facts the case turns on. Nothing else, or the emphasis stops working.
- *Italic* — instruction and statute cites, postures and recommendations, quoted
  report language run inline, and every *(verify)* flag.
- `>` blockquote — the best-issue flag line, and any quote long enough to stand
  on its own.
- Tables — elements and the bottom line. Never a wall of prose where a table fits.
- Quotes — verbatim, under ~25 words, always attributed to a narrative, witness,
  or supplement. Ellipses for trims; never alter wording to smooth it.
